# Дизайн-система Best Invest Properties

Дата: 25 вересня 2026  
Джерело: затверджений прототип Best Invest Properties

Документ описує кольори, шрифти, відступи й компоненти затвердженого дизайну —
у вигляді, потрібному для побудови інтерфейсу в Bubble.

## 1. Принцип системи

Палітра одна на весь продукт, але поверхні розділені на **три рівні світлоти**.

| Рівень | Де застосовується | Фон сторінки | Фон бічної панелі |
|---|---|---|---|
| 1 — публічний сайт | лендінг, каталог, об'єкт, аналіз, калькулятор, реєстрація, юридичні | `#F7FCFF` | — |
| 2 — кабінети | дашборд інвестора, портал забудовника | `#F7FCFF` | `#EAF2F8` |
| 3 — адміністрування | усі екрани адміністратора | `#F7FCFF` | `#EAF2F8` |

Усі три рівні світлі. Темні поверхні використовуються **точково**: герой
лендінга, шапки деяких внутрішніх екранів (`#0F3A60`) і toast (`#1D3E56`).

## 3. Типографіка

**Одна гарнітура — Archivo.** Ієрархію тримають вага, розмір, міжлітерний
інтервал і золотий акцент.

```
Archivo: 400, 500, 600, 700
Резервні: system-ui, sans-serif
Моноширинний: ui-monospace, Menlo, monospace
```

Моноширинний застосовується точково: номери юнітів, імена файлів, номери
розділів у юридичних сторінках.

### 3.3 Правила

- Заголовки H1 — **великими літерами**, вага 700, відʼємний інтервал.
- Лейбли секцій — великими літерами, 12 px, інтервал .16–.18em, колір `#566E80`.
- Висота рядка: 1.6–1.75 для абзаців, 1.05–1.2 для заголовків.
- Усі числові значення (ціни, дохідності, бали) — `font-variant-numeric:
  tabular-nums`, щоб колонки не «стрибали».
- Довгі абзаци обмежені `max-width: 62–74ch`.

## 4. Радіуси

| Значення | Застосування |
|---:|---|
| `40px` / `999px` | **пігулки**: усі кнопки, чипи, вкладки |
| `16px` | картки, панелі, великі блоки |
| `12px` | вкладені блоки, toast, підсумкові панелі |
| `10px` | поля вводу, примітки |
| `7px` | дрібні блоки списків, рядки документів |
| `4px` | чипи статусів, прогрес-смуги |
| `3px` | найдрібніші індикатори |

Кнопки **завжди пігулки**. Прямокутних кнопок немає.

### 5.2 Картки

```
background: #FFFFFF
border: 1px solid rgba(23,75,103,.05)
border-radius: 16px
box-shadow: 0 12px 34px rgba(23,75,103,.07)
padding: 20–26px
```

Варіанти: порожній стан — та сама картка з `border: 1px dashed
rgba(23,75,103,.14)`; акцентована — з лівою смугою `3px solid` кольору стану.

### 5.3 Поля вводу

```
background: #F0F7FC   (у формах забудовника — #FFFFFF)
border: 1px solid rgba(23,75,103,.18)
border-radius: 10px
padding: 13px 14px
font-size: 15.5–16.5px
placeholder: #8FA6B8
```

Стан помилки: межа `#B3453D`, повідомлення під полем 13.5 px кольором
`#8E362F`. Кожне поле підписане `Required` або `Optional` — підпис
обов'язковий, а не декоративний.

### 5.4 Чипи статусів

```
font-size: 12.5–13px
letter-spacing: .1em

border-radius: 4px
```

| Стан | Фон | Текст |

| Очікує | `rgba(221,180,94,.16–.22)` | `#174B67` / `#205A87` |

### 5.5 Таблиці

Заголовок: 12 px, інтервал .12em, вага 500, колір `#566E80`, нижня межа
`rgba(23,75,103,.1)`. Рядки: 15.5 px, нижня межа `rgba(23,75,103,.05)`,
відступ 11–12 px. Мінімальна ширина 520–620 px із горизонтальною прокруткою
на вузьких екранах.

### 5.6 Toast

```
position: fixed; bottom: 26px; left: 50%
background: #1D3E56; color: #FFFFFF
border-radius: 12px; padding: 13px 18px
box-shadow: 0 14px 34px rgba(10,31,56,.32)
max-width: min(460px, 86vw)
```

Автоматичне зникнення ~3.8 с, клік закриває, підпис «Dismiss» праворуч.

### 5.7 Модальне вікно

```
background: #FFFFFF; border-radius: 12px; max-width: 470px
box-shadow: 0 26px 60px rgba(10,31,56,.4)
overlay: rgba(10,31,56,.55)
```

Структура: заголовок 23 px / 600 → текст 16.5 px → необов'язкова примітка на
тлі `#D3E5F2` → необов'язкове поле причини → кнопки Cancel / підтвердження
(праворуч). Колір кнопки підтвердження: `#205A87` для звичайних і
золотих дій, `#8E362F` для небезпечних.

### 5.8 Логотип

Знак (подіум 1·2·3 з хвилею) висотою 48 px + текстовий блок:
«BEST» кольором `#0F3F8F` + «INVEST» із золотим градієнтом, під ними
«PROPERTIES» — 10 px, інтервал .42em, кольором `#0F3F8F`, з рисками
`#D9B25B` по боках. На лендінгу — повний логотип, усередині продукту —
спрощений.

## 7. Адаптивна поведінка

Інтерфейс перемикає компонування **на одній точці — 760 px**. Це не плавна
сітка: мобільна й десктопна версії відрізняються структурно.

| Елемент | Desktop (> 760 px) | Mobile (≤ 760 px) |
|---|---|---|
| Бічна навігація порталу/адмінки | колонка 210 px, ліва золота смуга активного пункту | горизонтальна стрічка з прокруткою, активний пункт — біла пігулка |
| Фільтри каталогу | ліва колонка | drawer із лічильником вибраних |
| Рейка «Top 5» | правий стовпець 268 px | переноситься **над** списком |
| Зміст юридичної сторінки | липка колонка 150–230 px | горизонтальна стрічка з пігулками |
| Секція юридичної сторінки | сітка `34px + текст` | один стовпець |
| Заголовок юридичної сторінки | 44 px | 30 px |
| Таблиці | повна ширина | горизонтальна прокрутка, `min-width` збережено |
| Головна навігація | горизонтальні посилання | бургер-меню, розкривна панель |

Прокрутка стилізована класом `.bip-scroll`: смуга 9 px, повзунок
`rgba(23,75,103,.2)`, радіус 16 px.

## 8. Доступність

Контраст розрахований за формулою WCAG 2.2 (відносна яскравість, sRGB).
Поріг для звичайного тексту: AA ≥ 4.5:1, AAA ≥ 7:1.

| Пара | Контраст | Оцінка |
|---|---:|---|
| `#0F3A60` на `#F7FCFF` | 11.33:1 | AAA |
| `#174B67` на `#F7FCFF` | 9.08:1 | AAA |
| `#36566B` на `#FFFFFF` | 7.78:1 | AAA |
| `#FFFFFF` на `#205A87` | 7.31:1 | AAA |
| `#B3453D` на `#FFFFFF` | 5.48:1 | AA |
| `#1B4258` на `#DDB45E` | 5.47:1 | AA |
| `#566E80` на `#FFFFFF` | 5.33:1 | AA |
| `#2F7D63` на `#FFFFFF` | 4.96:1 | AA |
| `#5B7485` на `#FFFFFF` | 4.90:1 | AA |
| `#FFFFFF` на `#087CB8` | 4.58:1 | AA (межово) |
| `#8FA6B8` на `#FFFFFF` | 2.53:1 | **не проходить** — лише placeholder |

Вимоги:

- `#8FA6B8` застосовувати **тільки** як placeholder, ніколи як змістовний текст;
- `#5B7485` (4.90:1) проходить AA, але запас малий — не використовувати для
  тексту дрібнішого за 12 px і не класти на тоновані поверхні, де контраст
  впаде нижче порогу;
- статус ніколи не передається лише кольором — чип завжди містить текст;
- напрям шкали «Risk & Investor Protection» має бути підписаний словами;
- мінімальна зона дотику — 44×44 px для всіх інтерактивних елементів.
